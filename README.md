# ПОТОЛОК

Курсовой проект — сайт услуг и магазина с административной панелью, FastAPI и PostgreSQL.

## Локальный запуск

1. Установите Python и PostgreSQL.
2. Создайте виртуальное окружение и установите зависимости из `requirements.txt`.
3. Скопируйте `.env.example` в `.env` и заполните настройки подключения к PostgreSQL и секрет администратора.
4. Создайте базу и таблицы командой `python DataBase/create_database.py`. Для заполнения каталога используйте `python DataBase/seed.py` один раз.
5. Запустите API из каталога `backend` командой `python -m uvicorn main:app --reload`.
6. Откройте `index.html` через локальный веб-сервер. Админка находится в `admin-login.html`.

Параметры онлайн-оплаты указываются в `.env`, когда подключён платёжный сервис. Файл `.env`, данные локальной базы и виртуальное окружение не входят в репозиторий. Схема БД находится в `docs`.
